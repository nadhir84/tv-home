# TCL 75C727 Google TV (device G05, "Smart TV Pro"), Android 11, build AR2101
# Apply: tools/disable.sh examples/tcl-75c727/debloat.txt   Undo: tools/restore.sh <same file>
# Everything is DISABLED for user 0, never uninstalled.
# Based on examples/tcl-google-tv-g07, keeping Chromecast, screen mirroring, USB/file playback,
# sideloading (packageinstaller, externalstorage, media/downloads providers) and HDMI/eARC/Dolby audio
# (com.tcl.tv, com.tcl.tvinput, com.tcl.settings, com.tcl.system.server, com.dolby.android.audio.service).
# USB: with USB debugging on, a reboot leaves the USB port in gadget mode (sys.usb.config=adb, Mstar-udc):
# USB drives don't mount and a USB Ethernet adapter gets power but no link. Turn USB debugging off and
# reboot when you're done; it is also what opens ADB port 5555, so turn it back on for the next session.
